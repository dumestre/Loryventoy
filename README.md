O Movimento é um software de animação procedural baseado em nós, que visa ser uma alternativa ao Adobe After Effects, Cavalry. 
Com uma interface limpa e intuitiva, o Movimento permite criar animações complexas com facilidade. 
Com o objetivo de ser uma ferramenta poderosa e acessível para motion designers, o Movimento oferece uma variedade de recursos para criação de animações.
